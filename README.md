# 🏀 NBA Stats Dashboard

Dashboard interactivo desarrollado en **Streamlit** para visualizar el historial de victorias y derrotas de equipos de la NBA por temporada, utilizando el dataset de ELO ratings de FiveThirtyEight.

##  Demo

https://nba-dashboard-cnnzd8tdrtolswgxvxelz8.streamlit.app/ 

---

##  Características

- Filtro por **año**, **equipo** y **tipo de juego** (temporada regular, playoffs o ambos)
- Gráfica de líneas con el acumulado de victorias y derrotas en la temporada
- Gráfica de pastel con la distribución de resultados
- Métricas rápidas: victorias, derrotas y porcentaje de victorias

---

---

##  Dataset

**NBA ELO Dataset** — FiveThirtyEight  
Contiene 126,314 registros de partidos NBA desde 1947 hasta 2015, incluyendo equipos, resultados, ratings ELO y tipo de juego.
